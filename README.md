# Гродно — Белосток

Разбор, какую дизельную машину смотреть на короткую дорогу Гродно — Белосток: бак, сумки, год, пробег и цена ремонта. Старый каталог на главной оставлен. Отдельная страница на 2018–2022 год — svezhie.html.

Сайт: https://fooooxmr.github.io/grodno-bialystok/

Цены в карточках — запросы из белорусских объявлений октября 2026, не сделки. Фото разложены по годам и взяты с объявлений av.by нужного поколения.

Бюджет на страницах — около 25 тысяч долларов. Старый каталог сохранён, в него добавлены варианты этого бюджета.
Отдельная страница, если бус уже не нужен: дизельные джипы и кроссоверы до 20 тысяч долларов — dzhip.html.
